# AI Agent Control Center

Yeh folder aapke AI Agents ke liye **Master Command Center** hai.
appko recruitment (project details) ko appko INSTRUCTIONS.md file me **PART 17 — BRIEF PLACEHOLDER**  me dalna hai baki sar work ai ker dega 

##  Main File:
- **[`AGENT_MASTER_INSTRUCTIONS.md`](./AGENT_MASTER_INSTRUCTIONS.md)**: 
  * Poora master manual jisme saare 913 skills ka index, trigger keywords, aur exact paths hain.
  * Multi-skill chaining recipes (multiple skills ko ek saath kaise use karein).
  * Har skill ke andar `scripts/` folder kab aur kaise check karna hai.

##  How to Give This to Any AI:
Bass is repository ko clone kera aur kisi bhi AI model (Claude, ChatGPT, Gemini, Cursor) ko boliye:
> *"Follow the instructions in `ai-agent/AGENT_MASTER_INSTRUCTIONS.md` for all tasks."*
